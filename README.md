## 洛杉矶机房的实际路由：Evoxt 走的不是 59.43

洛杉矶节点落在 WebNX 机房，Evoxt 有自己的 AS 号 AS149440。去程三条路径分别是：电信走 GTT 直达洛杉矶进 WebNX，联通走 Zayo 到圣何塞再转洛杉矶，移动先走 CMI 到日本再跨太平洋。

回程才决定用起来什么感觉。

| 运营商 | 回程路径 | 广州落地延迟 |
| --- | --- | --- |
| 电信 | AS149440 → WebNX → GTT → AS4134（163 骨干） | 156–206ms |
| 联通 | AS149440 → WebNX → Comcast 洛杉矶 → Comcast 芝加哥 → AS4837 | 173–195ms |
| 移动 | AS149440 → WebNX → Lumen 洛杉矶 → Lumen 法兰克福 → CMI 北京 → AS9808 | 250ms 以上 |

三条路径里一个 59.43 都没有。电信那条是 163 骨干直连，白天能压到 150ms 出头，晚八点以后跟着 163 一起抖；联通多绕了一趟芝加哥；移动先飞欧洲再回国，广州落地 250ms 起步，实时交互基本没法用。

这就是普通美西线路的真实水平。CN2 GIA 的判定标准是所有回程流量走 AS4809、节点 IP 以 59.43 开头，Evoxt 这里是 AS4134 和 AS4837，两条完全不同的路。

判断落到具体人身上：电信用户拿它当一台便宜的海外机器、跑不需要即时响应的任务，150ms 可以接受。拿它给国内用户开网站，晚高峰最先出问题的就是它。

## 怎么验证你买到的洛杉矶 CN2 GIA 是真的

商家页面写“CN2 优化线路”这六个字不构成任何承诺，路由追踪能。

**第一步，从国内追过去。** 找三台机器，电信、联通、移动各一台最好。Windows 用 `tracert 你的服务器IP`，Linux 和 macOS 用 `mtr -rw 你的服务器IP`。

**第二步，看 59.43 出现在哪个位置。**

- 全程几乎都是 59.43，直到进机房：真 GIA，去程全程走 AS4809。
- 国内段一大片 202.97，出海才跳出 59.43：只有出海段走 CN2，这是 GT。
- 去程 59.43，回程全是 202.97：半程方案，体验打对折，也是最常见的“伪 CN2”。
- 全程 202.97 或 AS4134：普通 163，跟 CN2 没有关系。

记住两个号段就够了，AS4809 是 CN2，202.97 是 163。商家文案可以随便写，骨干网节点 IP 改不了。

**第三步，单独测回程。** 去程只传请求，回程才是数据。你打开网页、看视频、下载文件，吃的是回程带宽。登录服务器，用 `mtr -rw 你家宽带的公网IP` 往国内追，或者用 besttrace 一类工具分别测电信、联通、移动三个方向。商家最容易在这里省成本：去程写得漂亮，回程悄悄换成 163。

三网回程全走 GIA 才是这个品类现在的配置基准，只有去程优化、回程走 163 的方案，晚高峰的差距会非常明显。
